# Invest Money website

A static, GitHub Pages-ready snapshot of the publicly served website at https://website-trust-and-ui-pfkz.bolt.host/ (captured 2026-10-17).

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder to the repository root.
2. In the repository, open **Settings → Pages**.
3. Set the source to the `main` branch and `/ (root)`, then save.

The site uses relative asset paths so it works at a GitHub Pages project URL.

## Bundle contents and limitations

This archive contains the public production HTML, compiled JavaScript and CSS bundles, and favicon from the hosted site. It is a deployable snapshot, not the original editable React/Vite source project; that source must be exported from the original Bolt project for normal source development. The JavaScript is minified as served by the host. The displayed Google Font is loaded from Google Fonts.

Review all financial claims and regulatory references in the site before publishing. The hosted page includes statements about guaranteed returns, capital protection, insurance, and regulatory status; this archive does not verify those claims.
